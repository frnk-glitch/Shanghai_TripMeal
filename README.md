# 🍜 상하이 맛집 지도 (Trip_Meal)

상하이 출장용 맛집 지도. **Leaflet + 고덕(高德/AMap) 타일** 기반이라 중국 본토에서도 잘 뜸.
배포: https://pages.oss.navercorp.com/mg-c/Trip_Meal/

## 쓰는 법
- **핀 클릭** → 중국어 상호 크게(택시기사에게 보여주기) + 가격/메모 + **고덕 길찾기** 링크
  - 마커 모양: 이모지 배지 핀(🔥 훠궈 · 🍜 면 · 🥟 만두/딤섬/생전 · 🐟🦆 대표요리)
  - `소윤★` = 조소윤 추천 · `유명` = 일반 유명맛집
- **퀵버튼(메뉴/유명맛집/체인)** → 누르면 **현재 지도 범위에서 검색해 🍴 마커로 표시**
  - 검색 우선순위: 텐센트(키 있을 때, 고품질) → OSM Nominatim(키 불필요 폴백, 음식점만 필터) → 결과 없으면 상단 바에 **고덕 검색 링크**
  - 상단 결과 바의 `고덕 ↗` 로 언제든 고덕앱에서 열기 · `지우기` 로 마커 제거

## 고품질 검색 켜기 (선택)
OSM 폴백은 일부 키워드(蟹粉面/葱油拌面/특정 로컬 상호)에 약함. 텐센트 키를 넣으면 정확해짐:
1. `cp config.example.js config.js` 후 `window.TENCENT_KEY` 에 lbs.qq.com 웹서비스 키 입력
2. 텐센트 콘솔에서 그 키의 **referer 화이트리스트에 `pages.oss.navercorp.com` 추가** (필수)
3. `config.js` 는 `.gitignore` 됨 → Pages에 배포하려면 별도로 올리거나, 키에 referer 락을 건 채 커밋

## 수정법
`index.html` 상단의 **`PLACES` 배열**(고정 마커)만 고치면 됨.
- `lat`/`lng` 는 **WGS-84(구글맵 좌표)** → 코드가 고덕용 GCJ-02 로 자동 보정
- 고덕 공유 단축링크(`surl.amap.com/...`) 좌표는 GCJ-02 이므로 **WGS-84 로 역변환 후** 입력(이중보정 ~500m 오차 방지)
- 필드: `cat`(분류), `ic`(마커 이모지), `by`("소윤"|"유명"), `price`, `note`, `amap`(고덕 링크), `blog`(선택)
- 퀵버튼은 `MENUS` / `FAMOUS_SEARCH` / `CHAINS` 배열에서 추가·삭제 (`{n:한글, k:중국어 검색어}`)

데이터 출처: 조소윤 추천 + 고덕 공유링크 좌표 + 네이버 블로그 + OpenStreetMap(유명맛집 좌표).
