# 🍜 상하이 맛집 지도 (Trip_Meal)

상하이 출장용 맛집 지도. **Leaflet + 고덕(高德/AMap) 타일** 기반이라 중국 본토에서도 잘 뜸.
배포: https://pages.navercorp.com/mg-c/Trip_Meal

## 쓰는 법
- **핀 클릭** → 중국어 상호가 크게 뜸(택시기사에게 보여주기) + 가격/메모 + **고덕 길찾기** 링크
- **하단 체인 퀵버튼** → 지점 많은 체인(양꼬치/에그타르트/밀크티/하이디라오)을 고덕앱에서 현재 위치 주변으로 바로 검색
- 모바일: 하단 바텀시트 손잡이를 올려 목록 펼침

## 수정법
`index.html` 상단의 **`PLACES` 배열**만 고치면 됨.
- `lat`/`lng` 는 **WGS-84(구글맵 좌표)** 로 입력 → 코드가 고덕용 GCJ-02 로 자동 보정.
- 고덕 공유 단축링크(`surl.amap.com/...`)에서 뽑은 좌표는 GCJ-02 이므로, 그대로 넣지 말고 WGS-84 로 역변환 후 입력(이중 보정 방지, ~500m 오차).
- `amap`: 고덕 공유링크(해당 지점 길찾기), `blog`: 네이버 블로그(선택).

체인 퀵버튼은 `CHAINS` 배열에서 추가/삭제.

데이터 출처: 조소윤 추천 리스트 + 고덕 공유링크 좌표 + 네이버 블로그 후기.
